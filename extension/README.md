# AIを用いた二輪ロボットの能動的外観検査

## 目的
画像認識で再観測が必要と判断したとき、二輪ロボットを別視点へ移動させます。その走行を教師データとして記録し、模倣学習（Behavior Cloning：BC）で再現しました。

## 仕組み
1. Gazeboで二輪ロボットを動かし、ROS 2で位置・画像・動作指令を取得
2. rosbag2へ教師走行8回・1,003サンプルを保存
3. 状態（距離・向きの誤差3値）と行動（直進・角速度2値）からMLPを学習
4. 学習モデルをGazeboへ導入し、従来制御と同じ8場面で比較

教師データは学習760サンプル、確認243サンプルに分離しました。経由点計画や地図情報は従来の処理を使用しており、画像から直接走行指令を学習する方式ではありません。

## 実験結果（8場面×2方式）

| 指標 | 従来制御 | BC |
|---|---:|---:|
| 目標到達 | 8/8 | 8/8 |
| 最終正判定 | 8/8 | 8/8 |
| 平均走行距離 | 4.104 m | 4.122 m |
| 平均時間 | 15.233秒 | 15.240秒 |

BCでも目標到達を確認しましたが、従来制御より性能が向上したとはいえません。認識方式を比べた144試行は親フォルダの `output/` に保存し、この16試行とは分けて集計しています。

## 主なコードと結果
- `pipeline.py`：データ収集・BC学習・比較
- `deploy.py`：認識結果に応じたBC走行
- `verify.py`：データと集計の検証
- `inspection.rviz` / `rviz_check.py`：RViz表示
- `output/bc_model.npz`：学習済みモデル
- `output/summary.json` / `output/trials.jsonl`：結果
- `output/submission_demo.mp4`：127秒の動画（ローカル保存）
- `output/submission_report.pdf`：9ページのPDF（ローカル保存）

生rosbag2、画像、動画などの大容量データはローカル側に保存しています。GitHubの軽量ログだけでは全データの再検証はできません。

## 実行例
リポジトリのルートフォルダで、Ubuntu / WSLのbashから実行します。

```bash
bash extension/run.sh build
docker compose run --rm research python3 verify_submission.py
bash extension/run.sh rviz
```

学習を取り直す場合は別コピーを使用し、元の結果を上書きしないでください。LeRobotDataset変換用の補助スクリプトはありますが、LeRobotでの学習は未実行です。

## 注意点
実験環境は既知の静的な障害物と限定的な亀裂形状です。認識の誤判定は残っており、未知環境や実機の安全性は検証していません。接触通知だけで無衝突を証明することもできません。
